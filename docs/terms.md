# 용어집 · 用词表

앱 화면 글은 이 표의 말만 쓴다 (한국어 = 원본, 中文 = 중국어 화면). 새 말이 필요하면 먼저 여기에 한 줄 넣고 쓴다.
AI 가 여러 갈래로 나눠 고칠 때도 이 표가 기준이다 — 같은 뜻을 다른 말로 쓰지 않는다 (예: 구매함 ≠ 샀어요 · 보유함, 已购 ≠ 已买 · 拥有).

## 말투
- 한국어: 문장은 해요체(`…했어요` · `…예요` · `…세요`), 버튼 · 칸 이름은 짧은 명사구(`이름 바꾸기`, `격자로 보기`). 칸 안 짧은 상태말은 `없음` · `지움` 처럼 끝낼 수 있다. 문장 끝 마침표는 붙이지 않는다 (여러 문장 설명만 예외). 나열은 ` · ` (가운뎃점 앞뒤 공백).
- 中文: 简体, 口语 "你"(不用"您"), 按钮 · 标签用短词(`改名`、`网格显示`), 提示句不加句号, 并列用 ` · `。不要翻成书面腔或客服腔。
  - 标点: 中文句子里用全角 `（）：；！？`, 括号里只有英文也用全角 (`没有账号连接设置（config/supabase.json）`)。全角标点前后不加空格。
  - 「」: 中文和「」之间不加空格 (`已把「{name}」加入已购`), 并列时照常 ` · ` (`「A」 · 「B」`)。名字用「」, 不用 ‘’ 或 ""。
  - 数字 + 量词中间空一格: `{n} 个` · `{n} 件` · `{n} 条` · `{n} 天前` · `第 {n} 集` · `约 60 MB`。日期连写: `{y}年{m}月` · `{m}月{d}日` · `{year}年起`。金额 `{n} 韩元` · `{n}万`。
  - 失败: `没能…` (`没能下载商品数据` · `没能保存：{error}`), 不用 `…失败` · `获取…`。받기 = 下载, 불러오기 = 加载。
  - "A 외 n" = `A 和另外 {n} 个`。
  - 韩文里的 `PB 한정` 一类数据值 (产品线 · 类别 · 频道 · 阶段) 存的还是韩文, 只在显示的地方 tr。几个画面都会显示的词放在 `lib/l10n/zh/common.dart`。
- 두 사람이 쓰는 앱이다 (주인과 남자친구). 상대를 `동생` · 弟弟/妹妹 로 쓰지 않는다 — `친구` · 好友.
