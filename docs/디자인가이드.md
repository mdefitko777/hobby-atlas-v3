# 디자인 가이드 — Hobby Atlas

> 화면마다 요소 번호 · 위젯 · 이름 · 원칙을 적은 표입니다. 3장 요소표는 각 화면 파일 맨 위 대응표에서 그대로 만들어집니다(`python tool/make_guide.py .`) —
> 화면을 바꾸면 그 파일의 대응표를 먼저 고치고 이 문서를 다시 만듭니다. 코드 주석의 같은 번호(`// D-6 P03`)로 찾아갈 수 있습니다.

## 0. 앱 한 줄

- **Hobby Atlas**: 건프라 · 베이블레이드 X · 포켓몬 · Fate · 마도카 마기카 · 아머드 코어 · 레고의 공식 상품 · 발매일 · 새 소식을 한곳에서 보고, 좋아요 · 구매함 · 도감으로 내 컬렉션을 기록하는 개인용 안드로이드 앱. 둘이 같이 쓴다(친구 · 사진 공유).
- **데이터**: Gunpula 저장소가 공식 사이트에서 매일 모아 GitHub Pages 로 내보낸 카탈로그를 받는다(`lib/data/catalog.dart`). 계정 · 동기화 · 친구는 Supabase.

- **전환 3방식**: 쌓기(push/pop · CupertinoPageRoute) · 옆으로(하단 탭/측면 탭 + IndexedStack, 밑줄 탭) · 덮기(showModalBottomSheet · showDialog · showGeneralDialog(필터 패널) · Drawer(서랍)).
  탭 **안에서** 바뀌는 보기(O 전체 목록 · G 도감 · 검색 판)는 새 화면이 아니라 그 화면의 `setState` 표시 변화입니다.
- **적응형** (창 너비 · 높이 기준, `MediaQuery.sizeOf` · `LayoutBuilder`, 기기 종류 · 방향 고정 없음):
  - 폰(너비 < 700): 위 아바타 줄 + 채널 바, 바닥 탭 바. 아래로 스크롤하면 탭 바가 숨고 카메라만 남음 (S-8). 아바타 줄 · 아이콘 줄은 늘 고정, 채널 바는 한참(400 쯤) 내려 읽어야 접히고 조금 올리면 다시 (S-13)
  - 가로로 눕힌 폰(너비 > 높이 · 높이 < 520): 측면 탭(S-5) — 아바타 · 🔍 / 탭 4개 / 🔔, 높이가 모자라면 측면 탭만 스크롤
  - 폴드 펼침 · 태블릿 · 넓은 창(너비 ≥ 700): **반반 화면**(S-12) — 왼쪽 = 폰 화면 그대로, 오른쪽 = 자세히 칸. 폴드 접힘선(`displayFeatures`)이 있으면 거기서, 없으면 왼쪽 45%(320–460)
  - D 상품 상세: 칸 너비 ≥ 720이면 사진 왼쪽 · 정보 오른쪽(D-13). H 캘린더: ≥ 720이면 달력 왼쪽 · 목록 오른쪽(H-7)
  - 격자(O · G · 게시물): 칸 너비로 열 수 계산. A 배너 높이 ≤ 화면 높이의 절반
  - 확인: `test/layout_test.dart` — 320×568 · 390×844 · 844×390 · 690×830 · 830×690 · 768×1024 · 1280×800 에서 주요 화면 넘침 0 (`flutter test`)

## 4. 디자인 가이드 글 — 모든 화면이 따르는 규칙

### 색의 뜻 (S-15 · `lib/theme.dart`)
- **목적**: 색만 보고도 "고를 수 있는 것"과 "이미 구매함에 있는 것"을 구분하게 한다.
- **내용**: 바탕은 흑백(검정 #111 · 회색 · 흰색). 포인트는 두 가지뿐: **파랑**(Gp.accent) = 고름 · 누를 수 있음 · 좋아요 · 안 읽음, **민트**(Gp.own) = 구매함(리본 ✓ · 구매함 칸의 옅은 테두리 · 인증 배지 · 수집 막대). 빨강은 삭제 · 로그아웃에만. 상품 사진 외의 큰 검정 바탕 + 흰 글자 면은 쓰지 않는다.
- **원칙**: P04 · P08

### 모양의 뜻 — ♡ · 리본 · 배지 (A-9 · D-6 · G-4b · O-4)
- **목적**: 같은 행동은 어느 화면에서나 같은 모양으로 누른다.
- **내용**: ♡ = 좋아요(갖고 싶다), 책갈피 리본 + → ✓ = 구매함(가졌다), 🏅 배지 · 도는 색 고리 = 내 사진으로 인증. 상품 카드 사진 위 · 도감 기체 칸 위에는 ♡ 만 — 구매함은 카드 · 칸을 길게 눌러 넣고 뺀다 (진동 + 되돌리기, QuickMarks · ProductTile · GuideCell, 2026-11-20). 구매함이면 칸 왼쪽 위 리본 ✓ (누르지 않음). 태그 칸은 왼쪽 위 리본 · 왼쪽 아래 ♡ (MarkOverlay). 버튼일 때는 같은 아이콘의 TogglePill, 상세 아래 버튼은 켜진 쪽에 ×n (길게 누르면 수량). 컬렉션 탭 아이콘은 리본과 겹치지 않게 모자이크 격자.
- **원칙**: P04 · P06

### 도감 칸 표시와 레벨 (G-4)
- **목적**: 하나 더 모을 때마다 "올라간다"는 느낌을 준다.
- **내용**: 칸 그림은 늘 컬러(흑백 · 흐림 없음), 상태는 칸 위 표시로만: 아직(그림 그대로) → ♡ 좋아요 → 리본 ✓ + 옅은 민트 테두리(구매함) → 내 사진 + 도는 고리 + 배지(사진 인증). 작품 · 세대 · 채널 고르기는 그림 + 이름만인 분류 칸(CategoryTile, 숫자 없음). 레벨(1 · 2 · 3점, 5점마다 Lv)은 왼쪽 위 아바타 옆 Lv · 레벨 시트에만 — 도감 화면에는 레벨 막대 · 수집 n / m · 칸 위 숫자를 두지 않는다 (2026-11-20). 읽는 법은 긴 범례 대신 서랍 › 사용법의 도감 묶음(G-2).
- **원칙**: P01 · P10

### 글자 6단계 (S-15)
- **목적**: 크기만 보고 정보의 높낮이를 알게 한다.
- **내용**: Gp.t11(배지 · 시간) · t12 = 12.5(보조 글) · t14(본문 · 버튼) · t16(시트 제목) · t19(화면 · 섹션 제목 · 상품명) · t24(가격 · 큰 숫자). 이 밖의 크기는 쓰지 않는다(코드에 숫자로 쓴 글자 크기 0개).
- **원칙**: P08 · P04

### 면과 층 (A-8)
- **목적**: 줄과 줄 사이 경계를 선 없이 보이게 한다.
- **내용**: 흰 바탕(#FFFFFF) 위에 흰 띠(SectionPanel)를 10dp 틈 + 0.5 머리카락 줄로 나눠 쌓는다. 흰 면 안 작은 상자는 Gp.soft. 제목 앞에는 파랑 막대(SectionHeader). 떠 있는 흰 버튼(Gp.raised)은 아바타 · 카메라 · 채널 타일에만.
- **원칙**: P08

### 접근성
- **목적**: 작은 화면 · 큰 손가락 · 낮은 시력에서도 쓸 수 있게 한다.
- **내용**: 보조 글자 #767676 이상(흰 바탕 대비 4.5:1, WCAG AA). 사진 위 ♡ · 리본 누르는 자리 44dp, 작은 × 40dp. 좁은 화면에서 글자는 말줄임 · 줄바꿈 · 축소(넘침 0을 테스트로 확인).
- **원칙**: P08 · P09

### 되돌리기와 확인 (F-7 · F-10 · D-12 · K-5)
- **목적**: 실수해도 바로 되돌릴 수 있게, 되돌릴 수 없는 일은 한 번 묻는다.
- **내용**: 켜고 끄는 일(좋아요 · 구매함 · 점등 · 읽음 · 알림 지우기)은 바로 하고 토스트에 "되돌리기". 여러 개 삭제 · 제보 · 로그아웃 · 기록 지우기는 먼저 확인 대화상자. 지운 상품은 휴지통에서 다시 켬.
- **원칙**: P03 · P05

### 표기 (D-5 · O-4)
- **목적**: 같은 정보는 같은 모양으로 쓴다.
- **내용**: 날짜는 어디서나 2027.09 · 2026.10.16 (dateDot). 엔화 = 일본 정가(상세 가격 위 "일본 정가"), 원화 = 국내 시세 · 내 구매가. 건담 작품명은 영어(The Witch from Mercury · Hathaway …), 한글 줄임말은 검색어로만 남김.
- **원칙**: P02 · P04

### 한 벌로 이어지는 상태 (S-16)
- **목적**: 한 곳에서 바꾼 것이 다른 화면에서도 같게 보이게 한다.
- **내용**: 좋아요 · 구매함은 맨 위 MarksHost 하나(UserStore): 홈 카드에서 ♡ → 컬렉션 목록 · 상세 버튼 · 내 정보 숫자 · 친구 컬렉션 "나도 있음"이 같이 바뀐다. 반반 화면의 "오른쪽에 연 것"도 PaneHost 하나 → 왼쪽 카드 테두리 · 줄 바탕.
- **원칙**: P04 · P01

## 5. 상태관리 포인트

## 7. 알려진 한계

- **폴드를 접으면** 오른쪽 칸에 열려 있던 화면은 닫힌다(왼쪽 탭 상태는 유지).
- **웹 미리보기**(`flutter run -d chrome`)에서는 공식 사이트 상품 사진이 CORS 로 안 보인다 — 폰 앱에서는 보인다.
- **공식 사진이 없는 상품**은 같은 기체의 다른 상품 사진을 빌려 쓰고 "참고 그림"으로 표시한다(D-2c). 열리지 않는 사진은 넘기기에서 뺀다(D-2d).
