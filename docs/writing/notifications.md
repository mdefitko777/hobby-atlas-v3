# 알림 · 通知

N 알림(🔔 — 소식 · 친구 요청), K 알림 페이지(채널마다 규칙 · 조건), 알림 조건 시트, 휴대폰 알림(제목 · 둘째 줄) · 안드로이드 알림 채널 이름. 백그라운드에서도 같은 글을 쓴다 (번역은 언어 파일을 읽어서).

## 문장 모양 · 예
- 휴대폰 알림 제목: `{규칙} · {이름}` — 상품 하나면 「」 없이 (`예약 도착 · HG 에어리얼` · `재판매 · HG 에어리얼 12월`), 여러 개 요약만 「」 (`「A」 · 「B」 외 {n}개`).
- 여럿: `{names} 외 {n}개` = `{names} 和另外 {n} 个`.
- 둘째 줄: `{채널} · {작품} · {라인}` — 작품은 `shortWorkName` (`건담 · SEED · HG`), 라인은 `dataLabel`.
- 이름 조각은 기록할 때 언어로 굳히지 않는다: 모든 알림 기록이 `NoticePart.value(ko, zh)` 를 가져 언어를 바꾸면 이름도 바뀐다.
- 빈 화면: `내 채널 새 상품 · 좋아요한 상품 변경 · PB 예약이 여기에 모여요`.
- 설명: `좋아요 · 구매함 상품의 재판매 소식` (`再販` 쓰지 않음).

## 하지 말 것
- 같은 일을 채널 · 규칙 · 요약에서 다른 이름으로 (`프리미엄 반다이 예약` / `PB 예약 기간` / `PB 예약`).
- 오류 글 · 예외를 `tr` 없이 토스트로.
- `NoticePart.key('프리미엄 반다이')` 를 PB 한정 뜻으로 (→ `PB 한정`).
