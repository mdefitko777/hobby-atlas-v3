# 홈 · 首页

A 홈: 큰 배너(예고) + 줄마다 가로 스크롤(이번 달 발매 · 새 상품 · 공식 예고 · 최근 본 상품), 홈 › My Page(♡ 좋아요 · 리본 구매함 · ★ 특별 관심), 앱 셸의 위 줄(찍어서 찾기 시트 · 🔔 · ⚙)과 아래 탭, 채널 바 · 채널 관리.
상품 카드(홈 줄 · 전체 목록 · My Page)는 사진 + 이름 두 줄, 사진 위에는 ♡ 만 — 구매함은 카드를 길게 눌러 넣고 뺀다 (진동 + `「{name}」 구매함에 넣었어요` · `구매함에서 뺐어요` 토스트, 되돌리기). 내용을 내려 읽으면 위 줄 · 채널 바가 접히고 검색창 줄만 남는다 (글 없음).

## 문장 모양 · 예
- 빈 화면: `내 채널이 비어 있어요` + `채널 관리에서 채널을 추가해 보세요` = `我的频道是空的` + `去频道管理里添加频道`.
- 채널에 상품이 없을 때: `{channel} 상품이 아직 없어요` = `{channel}还没有商品` (`은(는) 아직 수록된` 쓰지 않음).
- 새 소식 없음: `새 소식이 없어요` + `상품이 들어오면 여기에 먼저 보여요`.
- 도움말(HelpButton): 아이콘 + 짧은 명사구 `My Page (내 것 · ★ 친구)` · `공유 카드 (My Page 숫자 줄 끝)` · `격자 · 목록 (전체 보기 안)` · `상품 카드 길게 = 구매함에 넣기 · 빼기`.

## 하지 말 것
- `IP` · `관심 IP` (→ 채널), `최근 본` 으로 끝내기, `최근 추가` · `새로 들어온` (→ 새 상품), `앨범에서 선택` (→ 사진으로 찾기), `바코드 스캔` (→ 바코드로 찾기).
- 줄 제목 옆 상품 수.
- 상품 카드에 구매함 버튼(리본 +)을 다시 두기 · `구매함 담기` · `샀어요` (→ 구매함에 넣기).
