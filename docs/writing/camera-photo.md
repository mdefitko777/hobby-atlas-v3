## 문장 모양 · 예
- 모델 받기: `사진 속 생김새로도 찾기 · 처음 한 번 모델 받기 ({size}, 와이파이 권장)` = `也能按照片里的外形找 · 首次需下载模型（{size}，建议用 Wi-Fi）`.
- 모델 지우기 (여러 문장): `받아 둔 생김새 모델(약 105 MB)을 지워요. 다시 쓰려면 또 받아야 해요.` = `会删除已下载的外形模型（约 105 MB）。要再用就得重新下载。` 버튼 `지우기` · `취소`.
- 사진 넣은 뒤: `「{name}」에 사진을 넣었어요` = `已把照片加到「{name}」`.
- 오류는 `…하지 못했어요` + 원인 괄호: `사진을 가져오지 못했어요 ({error})`. 오류 글(생김새 데이터 · OCR)도 `tr` 을 거친다 — `Exception:` 머리는 떼고.

## 하지 말 것
- 지우기 확인창의 취소를 `그대로` 로, 다시 시도를 `다시` 로.
- `모양` · `표` · `앨범` · `붙이기` · `잇기 · 끊기` · `축척` · `낱말`.
- 오류 객체를 그대로 (`'${e}'`) 화면에.
