# 컬렉션 · 도감 · 베이 · 收藏 · 图鉴 · 陀螺

F 컬렉션(좋아요 · 예약 · 구매함 · 도감 · 편집 · 휴지통 · 지출 요약), G 도감(건담 시대 · 작품 · 기체, 세계관 묶음, 메자스타 · 프렌다 태그, 베이 부품), T 조합 만들기 · 덱.
도감 화면 모양 = 검색 탭 종류 · 세대: 왼쪽 묶음 목록(건담 = 시대 머리 아래 작품 · 세계관 = 세대 묶음 · 베이 = 베이 · 블레이더) + 오른쪽 칸(그림 + 이름, ♡ · 리본 표시). 기체 칸 그림 위는 상품 카드와 같이 왼쪽 위 리본 + (구매함 넣기 · 빼기) · 왼쪽 아래 ♡ (구매함이면 리본 ✓ + 민트 테두리). 길게 누르기는 쓰지 않는다 (2026-11-20 주인이 리본 + 로 되돌림). 묶음 목록 말은 [search-browse.md](search-browse.md) 그대로 (`묶음 펴기` · `묶음 접기` · `왼쪽 묶음을 누르면 그 묶음의 칸만 · 밀어서 펴고 접기`).

## 문장 모양 · 예
- 줄 부제: `{채널} · {라인} · {작품}` — 같은 말은 한 번 (`포켓몬 · 봉제인형`, `포켓몬 · 봉제인형 · 포켓몬` ✗), 한 채널만 보면 채널 빼기. 라인은 `dataLabel`, 작품은 `shortWorkName` — 건담은 도감의 공식 작품 이름 (`역습의 샤아`, Gunpula series 줄임말 `역샤아` ✗). 코드 `kitMetaLine` · `kitWorkName` (`lib/logic/kit_meta.dart`, 친구 컬렉션 · 캘린더도).
- 탭 · 목록 머리에는 수를 쓰지 않는다 — 합계는 목록 맨 끝 `ListSummary` (`lib/widgets/sections.dart`, 캘린더 내 일정도).
- 확인: `{n}개를 구매함에서 지울까요?` = `要从已购删除 {n} 个吗？`, 끝 `{n}개를 지웠어요` = `已删除 {n} 个`.
- 휴지통: `지운 상품은 30일 동안 여기서 복원할 수 있어요` · `휴지통 (30일 동안 복원)` · `「{name}」 복원했어요` = `已恢复「{name}」`.
- 조합: `「{name}」 지웠어요` (‘’ 쓰지 않음).
- 베이 부품 수: `보유 부품 {owned} / {total}` (다른 도감 `수집 {owned} / {total}` 과 같은 순서).
- 이름은 데이터 순서대로 ([data-names.md](data-names.md)): 화 제목 · 태그 · 부품이 일본어뿐이면 en, 그것도 없으면 번호만.

## 하지 말 것
- `삭제` · `되살리기` · `가짐` · `가진` · `점등` · `산 상품` · `한 격자` · `게임 세대` · `이로치`.
- 조사를 고정으로 붙이기 (`가진 {slot}가 없어요` → `보유한 {slot} 없음`).
- 태그 부제에 일본판 이름(local) · 일본어 변형 이름.
- 컬렉션 탭 옆 수 · 목록 위 `7개 · 합계 ¥…` 줄 · 조립 상태 칸(미조립 n · 조립 중 · 완성) · My Page · 내 정보 · 공유 카드의 미조립 숫자 — 2026-11-20 뺐다 (기록은 남김).
- 분류 칸에 상품 수 (내 진행 `수집 n/m` 은 검색의 도감 줄에서).
- 도감 화면(태그 도감 포함)에 레벨 막대 · `수집 n / m` · `좋아요 n` · 칸 위 숫자 꼬리표(베이 `n/3`) · 탄 칸 진행 막대 — 진행은 칸 표시(♡ · 리본 · 사진)로만, 부품 수는 부품 시트에.
